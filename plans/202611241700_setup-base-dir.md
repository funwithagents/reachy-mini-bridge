# Relative paths in the setup contract: `base_dir`

**Status:** Done

Implements `specs/core/setup.md` "Relative paths: `base_dir`" and `specs/core/config.md` "Relative paths": the contract's four machine-facing functions take `base_dir` and pass it to tts-engine's for the `tts` block; the loader takes the same folder, resolving a relative `daemon.scene` file and giving the `tts` block its `module.base_dir`.

## Scope

- `src/reachy_mini_bridge/config.py` — `base_dir` on `from_dict` / `from_json` / `from_json_file`; `resolve_scene`
- `src/reachy_mini_bridge/setup.py` — `base_dir` on `check_setup`, `prepare`, `options`, `probe`; the scene file item
- `tests/test_setup.py` — `base_dir` reaching the `tts` block's functions, a relative scene file, a relative voice file
- `pyproject.toml`, `uv.lock` — module-setup from its `base-dir` branch; tts-engine at its `setup-contract` with `base_dir`
- `specs/core/setup.md`, `specs/core/config.md`, `specs/_index.md` — the design, the statuses

## Steps

1. The loader's `base_dir`; `resolve_scene`; the `tts` block's `module.base_dir`.
2. The four functions' keyword, passed on; the scene item.
3. Relock on module-setup `base-dir` and tts-engine's latest `setup-contract`.
4. Tests; statuses.
