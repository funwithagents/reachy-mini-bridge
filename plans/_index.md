# Implementation plans

Implementation plans for Reachy Mini Bridge — each plan turns a settled part of a spec (see [specs/_index.md](../specs/_index.md)) into concrete, buildable steps. Plans are ordered by their date-time filename prefix (`YYYYMMDDHHmm_`).

The folder is pruned over time: it keeps the recent plans only, and older ones — every plan already `Done` and built into the code — are removed along with their rows. A pruned plan stays in the git history (`git log --all -- plans/<file>`); the specs, not the plans, are the lasting record of the design.
